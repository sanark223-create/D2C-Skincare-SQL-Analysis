# D2C Skincare Brand - SQL Data Analysis

## Project Overview
This project focuses on analyzing customer behavior, product performance, and sales trends for a Direct-to-Consumer (D2C) skincare brand using SQL.

## Core Questions Answered
* **Customer Retention:** Monthly repeat purchase rates.
* **Product Performance:** Top revenue-generating skincare categories.
* **Sales Trends:** Impact of seasonal promotions on revenue.
